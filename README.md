# Timer de Descanso

Timer de descanso entre séries, feito só com HTML, CSS e JavaScript.

## Como usar

1. Escolha a duração do descanso.
2. Toque em **Iniciar**.
3. Quando o tempo acabar, o app toca um aviso e soma uma série ao contador.

## Como rodar

Abra o arquivo `index.html` no navegador. Não precisa instalar nada.
