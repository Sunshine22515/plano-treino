# Plano de Treino

App para montar um plano de treino escolhendo exercícios de uma lista, feito só com HTML, CSS e JavaScript.

## Como usar

1. Busque um exercício pelo nome ou filtre por grupo muscular.
2. Toque em **Adicionar** para colocá-lo no plano.
3. Ajuste as séries e as repetições de cada exercício.

O plano fica salvo no navegador do aparelho que você usar.

## Como rodar

Abra o arquivo `index.html` no navegador. Não precisa instalar nada.
